諾文小鎮 v3.2.0（手機網頁 App／PWA）
====================================

■ 怎麼放到 iPhone 主畫面
PWA 必須放在一個 https 網址上，iPhone 才能「加入主畫面」並全螢幕開啟。
最簡單的兩種免費方式（擇一）：

A. Netlify Drop（不用寫程式）
   1. 用電腦打開 https://app.netlify.com/drop
   2. 把整個「novum-town」資料夾拖進網頁（需註冊免費帳號才能保留網址）
   3. 會得到一個 https://xxxx.netlify.app 網址

B. GitHub Pages
   1. 建一個新的 repository，把資料夾內所有檔案上傳
   2. Settings → Pages → Branch 選 main → Save
   3. 網址是 https://你的帳號.github.io/repository名稱/

拿到網址後，在 iPhone：
   用 Safari 開啟網址 → 點「分享」→「加入主畫面」→「新增」
之後點主畫面圖示，就像一般 App 一樣全螢幕開啟；第一次開過之後，沒有網路也能玩。
注意：iPhone 會把「主畫面 App」和「Safari 分頁」的進度分開保存。

■ 居民的自主性（v2.6）
自主聚會：同一個地方的人會自己聊開，你只會看到一段摘要（誰、在哪、聊了什麼），好感照樣上升；離線補算時也會發生，所以回來時可能發現誰跟誰變熟了。
自己約人：大家會用手機互傳訊息，約今天稍晚在某個地方碰面，答應了就真的會一起出現；感情很好時，偶爾有人會蹺課赴約。
小圈子：常常湊在一起的三個人會變成一個有名字的小圈子，有自己的群組聊天，每週固定一天在老地方聚會。
關係里程碑：兩個人變成朋友、好友、戀人時會留下紀錄（在哪裡、因為什麼事），在「💗 關係」裡可以看到。「你不在的時候」也會列出這段時間變熟的人。
固定配對：史威特×沏萊爾、佐代×禮、玫君×何禹瀧、白×海爾，預設開著戀愛線，好感夠了會自己告白，而且一定成功。
相遇不強制：觀察時有人聊起來，會先問你「要聽聽看嗎」，不聽的話他們照樣聊完，只留下一行紀錄；兩分鐘沒理會也會自己聊完。
加快進程：手機傳訊息沒有每天的次數限制；告白與約會不再擲骰；設定裡可以選「進展速度」慢／一般／快。

■ 小鎮的生活層（v2.5）
離開期間：重新打開網站時，會補上你不在的這段時間，跳出「你不在的時候」，列出大家的對話、八卦、借東西、怪事。
蝴蝶效應：小事會引出後續。借了東西會還、還了會回禮；你安排的分點心、幫忙會換來謝禮，捉弄別人會被報復；東西弄丟了，主人會到處找。
小鎮八卦：發生的事會變成消息，在大家碰面時一個傳一個。日誌的「💭 八卦」可以看每則消息傳到誰、怎麼傳的。
物品流轉：每個人都有一樣隨身小東西，會被借走、忘在某處、被撿到、還回去。日誌的「🎁 物品」可以看每樣東西的經歷；觀察時會顯示他身上帶著誰的東西。
紀元層異常：EL-7 偶爾會冒出舊紀元的怪現象，3D 小鎮上那個地點會出現紫色光環；在場的人會記住，隔天有人跑去調查，可能撿到舊紀元的東西。
地點記憶：點一個地點，可以看到「📜 這裡的記憶」：誰最常來、這裡發生過什麼、有沒有人把東西忘在這。
無聲互動與每日焦點：要好的人有時不說話，只是安靜地待在一起。每天有一個焦點（例如「慵懶的一天」「消息滿天飛」「紀元層不穩」），顯示在小鎮上方，點一下看說明，會影響當天八卦、借東西、怪事和安靜相處的多寡。

■ 怎麼玩
小鎮（3D）：預設是立體小鎮。拖曳移動、雙指縮放與旋轉。
      點居民跳出小卡（觀察／鏡頭跟著他／看地點），點建築看裡面有誰。
      居民會沿著街道走去下一個行程，同處的人會冒泡泡閒聊，一個人時會自言自語。
      有日夜、亮燈的窗戶、雨、霧、星空、螢火蟲；頭上冒 💬 的地點可能有相遇。
      左上角 ⏸／1×／5×／20×／+1h 控制小鎮時間；右上角 🏠 回全景、🏷️ 地名、📍 跟隨。
      上方可以切回「🗺️ 街區圖」。裝置不支援 3D 時會自動用街區圖。
放著看：3D 小鎮右上的 📺。全螢幕、沒有按鈕，鏡頭自己去找正在聊天的人，對話用字幕帶出來；點一下回來。
音樂：右上角 🎵 播放 lofi（即時合成，離線也能播）；設定裡可以調音量。
自己決定要去哪：每個人會肚子餓、累、無聊，臨時跑去吃東西、提早回家、晃去別的地方，不只照行程表走。
日記：晚上九點半後，每個人睡前寫一行今天的事，在日誌的「📓 日記」翻看（保留兩週）。
小生命：Hale’s Oven 門口的花貓、在屋頂間飛的貓頭鷹、公園的鴿子、街上路過的鎮民。
街區圖：切換四個區域（中央／學院／舊城／外城），點地點看看誰在那裡。
居民：點一位居民開始觀察。只有正在觀察的人會發生相遇對話。
      每句停在畫面上，按「下一句」才繼續；看完按「繼續觀察」等下一次相遇。
日誌：「我讀過的」是真的看完的紀錄，可依角色篩選、搜尋台詞；
      「事件圖鑑」列出所有可能的相遇，未讀的顯示 ？？？。
觀察畫面的四個按鈕：
  🧭 指派去…   把角色帶到別的地點待 30 分～2 小時，時間到回原本行程（休息中叫不動）
  💬 找人互動   對同地點的人「聊天／分享點心／請對方幫忙／逗一下」，雙方各用自己的語氣回應
  📱 偷看手機   看這個角色所在的群組與私訊，今天還沒發生的會顯示成昨天的
  💗 關係     看這個人和每個人的好感；可以為兩人「開啟戀愛線」
  📇 角色資料
聚會：小鎮畫面的「🎉 發起聚會」。選聚會種類、地點、邀請誰（最多 16 人），出席者彼此好感 +10；每天一次。
節日：鐘塔校時祭（每月1日）、紀元交換市集（7日）、第十三盞燈之夜（13日）、蒸氣列車紀念日（20日）、烤爐感謝祭（25日）、星落夜（28日）、佐代的生日（11/16）、霧燈散步會（起霧）、雨天騎樓茶會（下雨）；另有隨時可辦的慶功宴、火鍋、野餐、讀書會、演唱會。預覽模式可以模擬節日。
出遊：互動選單的「🧺 一起出去玩」（好感 55 以上），從 14 個地點選；週末下午好感 70 以上的人也會自己約出去。
自主行動：空閒的人會自己跑去找要好的朋友（已經和很要好的人在一起時不會離開）；聚會結束後大家會陸續散去。
日報：日誌裡的「📰 日報」，把今天的消息整理成一份小報。
關係圖：「💗 關係」裡可以看全鎮關係圖，點人就能切換觀察。
通知：右上角 🔔，大家自己互動、出遊、聚會、交往時會跳出消息。
今天的動態：觀察時可以看到這個人今天去過哪裡、跟誰在一起、聽說發生了什麼（大家會自己互動；戀人會有不一樣的互動）。
角色之間的訊息：好感夠高的人會自己互傳訊息，交往中的兩人一天會傳好幾次、內容更甜。
相遇提示：地圖上有 💬 的地點、名單裡標「可能有相遇」的人，觀察他們可能會碰上對話。
手機傳訊息：偷看手機時可以用那個人的手機傳固定訊息（早安、關心、分享照片、晚安、貼圖），對方會回覆；每天前三則會增加兩人好感。
日常事件好感：看完兩人以上的相遇，出場的人彼此好感 +1（設定裡可關閉）。
平面圖：點平面圖上的人可以直接切換觀察對象。點地點或在觀察畫面，可以看到室內格局與每個人的位置，人會慢慢走動；💬 是正在說話、💤 是睡著。
戀愛系統（不會自動發生）：
  好感只因你安排的互動而改變（每個人吃的招不同，例如逗癇癪會扣分）。
  沒開戀愛線時好感最多到 84；開啟後好感 70 可約會、85 可告白，對方可能拒絕；交往後可說心裡話。
  開放規則：成年角色之間、高中生之間（玫君、何禹瀧，只有甜甜的曖昧）；成年與未成年之間、國中生、年齡未設定的角色與家人不開放。年齡設定在 data/relations.js。
一個人的時候：也有獨處片段（自言自語、看手機、整理東西……）。
深夜也有事件：有人失眠、有人夜釣、有人熬夜；睡著的人偶爾會說夢話。
右上角時間或齒輪：切換「現實時間（台灣）」和「小鎮時間（自由流動）」。
      小鎮時間不跟現實同步：可以 1×／5×／20× 加速、暫停，也能調星期、時間、天氣。
      關掉 App 時小鎮會停住。進度和台灣時間分開保存。

data/schedules.js      每位居民的行程與住處（住處皆為暫定）
data/events-new.js     新撰寫的事件（72 則，含動作敘述）
data/events-more.js    第二批長對話、深夜事件、睡夢片段（34 則）
data/events-original.js 由您提供的 JSON 轉換的原始 324 則
data/events-solo.js    獨處片段（40 則）
data/voices.js         角色語氣庫上半（互動選單、戀愛台詞、自言自語、稱呼表）
data/voices-b.js       角色語氣庫下半，以及固定拌嘴組合（玫君×何禹瀧、史威特×沏萊爾……）
data/relations.js      起始好感、固定關係、年齡組別
data/phone.js          手機群組與私訊
data/phone-voices.js   手機固定訊息與回覆
data/festivals.js      節日、聚會台詞、出遊地點與台詞
data/floorplans.js     室內平面圖（觀察畫面用）
data/diary.js          睡前日記的句子
js/lofi.js             lofi 背景音樂
data/interiors.js      3D 室內家具（每個人的房間照代表色和興趣布置，可自己改）
js/engine.js           行程／相遇規則
js/app.js              畫面與觀察流程
js/town3d.js           3D 小鎮（three.js）
vendor/three.min.js    three.js r128（MIT 授權），離線也能用
icons/avatars/         角色頭像（av01～av16，對應表在 data/characters.js 最下面）
sw.js                  離線快取（更新內容後把裡面的版本號 +1）

進度存在瀏覽器 localStorage，只在這台裝置、這個瀏覽器有效。
設定裡可以「複製備份」「貼上還原」。
